# VESA and CTA timing table

See `VIDEO_MODES.md` for the current indexed mode list. The table contains
validated VESA DMT timings plus progressive CTA-861 HDMI timings accepted by
the Lenovo G24e-20 test monitor. Modes that showed artifacts or were outside
the monitor's supported vertical-frequency range were removed.

CTA entries carry AVI InfoFrame metadata through TDA9983B IF2.
